
# IT Committee Website — Frontend

Frontend частина вебсайту ІТ-комітету.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Installation

Install dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
